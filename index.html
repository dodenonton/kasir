Pengaturan Sinkronisasi Google Sheets

Hubungkan aplikasi kasir ini ke Google Spreadsheet Anda via Google Apps Script (GAS) Web App URL.

Dapatkan URL ini setelah menerapkan (deploy) Web App di Google Sheets.

PIN ini digunakan untuk membuka menu Laba Rugi, Master Barang, dan Pengaturan.

Cara Menghubungkan ke Google Sheets:

  1. Buka file google-apps-script.js yang telah kami sediakan di folder project ini.
  2. Buat Google Spreadsheet baru di Google Drive Anda.
  3. Klik menu Ekstensi → Apps Script.
  4. Hapus kode bawaan dan tempel kode dari google-apps-script.js.
  5. Klik tombol Terapkan (Deploy) → Penerapan Baru (New Deployment).
  6. Pilih jenis Aplikasi Web (Web App), isi:
    • Jalankan sebagai: Saya (Email Anda)
    • Siapa yang memiliki akses: Siapa saja (Anyone)
  7. Salin URL Aplikasi Web yang muncul dan tempelkan ke kolom URL di atas, lalu klik Simpan.
